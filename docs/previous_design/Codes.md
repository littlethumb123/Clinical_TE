### ICD-10-PCS codes (start with 'prcdr_cd' in the 'cd' column)
ICD-10-PCS is a procedure classification published by the United States for classifying procedures performed in hospital inpatient health care settings. This system uses a 7-character alphanumeric code to provide a standardized and detailed way to document procedures. The codes are broken down into specific components such as the root operation, body system, and approach to categorize procedures for a variety of purposes, including research and healthcare administration. 
- Root Type: The first character is a letter indicating the root type of the procedure.
- Body System: The second character is a digit or letter representing the body system involved.
- Root Operation: The third character is a letter defining the objective of the procedure, such as cutting, bypassing, or imaging.
- Body Part: The fourth character is a letter indicating the specific body part.
- Approach: The fifth character is a letter describing the approach used, such as open, percutaneous, or endoscopic.
- Device: The sixth character is a letter specifying the device used, if any.
- Qualifier: The seventh character is a letter providing further details about the procedure. 

The structure of the 7-character code is as follows, with an example based on a right knee replacement (code 0SRD0JZ): 
- 1st character: Section
    - Identifies the broad category of the procedure. There are 16 sections, including Medical and Surgical, Obstetrics, and Imaging.
    - Example: 0 = Medical and Surgical
- 2nd character: Body System
    - Defines the general body system or anatomical region where the procedure is performed.
    - Example: S = Lower Joints
- 3rd character: Root Operation
    - Identifies the objective or intent of the procedure, such as Excision, Repair, or Replacement.
    - Example: R = Replacement
- 4th character: Body Part
    - Specifies the specific anatomical site where the procedure was performed.
    - Example: D = Knee Joint, Right
- 5th character: Approach
    - Defines the method or technique used to reach the operative site. Options include Open, Percutaneous, or Laparoscopic.
    - Example: 0 = Open Approach
- 6th character: Device
    - Indicates any device that remains in place at the end of the procedure. A "Z" is used if no device is left.
    - Example: J = Synthetic Substitute
- 7th character: Qualifier
    - Provides additional information, such as diagnostic criteria or a specific attribute of the procedure. A "Z" is used if no qualifier applies.
    - Example: Z = No Qualifier

- 1 Obstetrics
