Section 1

System View

The architecture has two major levels. A daily encoder converts each day from an unordered set of up to 80 medical codes into one day vector. A temporal encoder then processes up to 200 day vectors with causal attention and extracts the last valid day as the member embedding.

Section 3

Temporal Reasoning

The temporal encoder is where the sequence stops being a stack of independent day vectors and becomes a trajectory model. The causal mask keeps the model temporally honest, and the key subtlety is that the visible history does not expand after Layer 0. What changes across layers is the meaning of each visible day representation.

Causal mask
Day t only sees days 1..t
D1D2D3D4D5
D1YNNNN
D2YYNNN
D3YYYNN
D4YYYYN
D5YYYYY
The mask prevents leakage during next-day prediction and guarantees that the extracted embedding only summarizes observed history. Day 4 can see Days 1-4 immediately in Layer 0, but it can never see Day 5.
Inside one layer
1. Pre-norm

Normalize each day vector before the main operation. This stabilizes gradients across six stacked layers.

2. Flash attention + RoPE

Project to queries, keys, and values, apply rotary positional encoding, then attend over only the allowed past days. This is where each day mixes with its available history.

3. SwiGLU feed-forward

Apply a gated MLP to each position independently after attention mixes temporal information.

4. Residual add

Carry forward the prior representation so each block refines rather than replaces.

Shape Ledger

The table below makes the full tensor path explicit, from raw hierarchical claims to the final embedding and pretraining head. Use it as the quick-reference version of the architecture.

Raw member history [B, 200, 80] Padded day/code hierarchy Up to 200 days, each day with up to 80 unordered codes Still symbolic and sparse
Embedding lookup [B, 200, 80, 256] Learned embedding table Each code becomes a 256-d vector Symbolic codes become dense local features

Demographic injection [B, 200, 256] Residual sum with age, gender, LOB embeddings Each day vector is conditioned by static member context Sequence shape stays constant, meaning gets richer
Temporal encoder output [B, 200, 256] 6 layers of causal attention + SwiGLU Each day row now encodes its full preceding history Rows become context-aware and more structured
Member embedding [B, 256] Take the last valid day row Single trajectory vector for downstream tasks Sequence collapses into one member representation
Prediction head [B, 200, 6297] Linear projection + BCEWithLogitsLoss Next-day multi-label grouped-code prediction Used for pretraining supervision, not final embedding storage
What the final 256-d vector still knows
  • Which diagnoses, procedures, medications, and utilization patterns have accumulated over time.
  • How recently those events occurred, because causal attention makes recent history available to the last valid day.
  • Trajectory-level interactions such as recurrence, escalation, and transitions between states of care.
What the final vector no longer stores directly
  • The original human-readable code list or a one-to-one mapping back to raw code slots.
  • Exact ordering among codes inside one day, because the daily encoder treats them as an unordered set.
  • Future information beyond the last valid day, because the causal mask blocks it at every layer.
